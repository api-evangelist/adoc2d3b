# Adoc (Viva Innovation)

> Adoc is the corporate web presence of Viva Innovation Inc. (주식회사 비바이노베이션), a Seoul,
> South Korea health-technology company founded in January 2018, which operates the health-checkup
> and medical-records platform 착한의사 (Chakan Uisa / Kindoc), the Kindoc Care CMS/PMS medical
> cloud for checkup centres, and the generative "주치의 AI" assistant Kindoc AI / Dr.Patch.
> As of 2026-09-07 the company publishes NO developer portal, NO API reference, NO SDK and NO
> machine-readable API contract (OpenAPI, GraphQL, AsyncAPI, MCP, A2A agent card) on any host it
> operates. This file is generated by API Evangelist from the catalog record, not published by the
> company.
